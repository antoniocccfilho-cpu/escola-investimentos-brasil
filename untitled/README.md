## O projeto

A Escola de Investimentos Brasil é uma plataforma existente de educação financeira voltada a iniciantes. O trabalho acadêmico organiza cursos, integra aulas interativas e prepara uma demonstração verificável da experiência do aluno. **Não há reconstrução da infraestrutura neste escopo.**

**Protótipo / plataforma:** https://smart-wealth-pragmatic-path.base44.app
